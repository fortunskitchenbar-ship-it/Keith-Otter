                  Architecture

                  Browser (this page)
   │  static shell + vanilla JS modules, IndexedDB/localStorage store
   ├── /api/weather   → Open-Meteo (live, 10-min edge cache)
   ├── /api/news      → RSS feeds (live, 15-min edge cache)
   ├── /api/markets   → Yahoo Finance + CoinGecko (2-min cache)
   ├── /api/ai-corner → DeepSeek (fallback: Gemini)
   ├── /api/status    → deployment + GitHub Actions health
   ├── /api/state     → Supabase (optional sync, token-gated)
   └── /api/agenda-brief → short AI greeting

GitHub Actions ──commit JSON──▶ Vercel auto-deploy ──▶ this page
n8n / Zapier ──webhook──▶ same JSON or Supabase
